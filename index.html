一起來挖礦、蓋房子、學新東西！

第一步：下載安裝程式

按下面的綠色按鈕，把 Minecraft 安裝程式下載到電腦裡。

⬇️ 下載 Minecraft 安裝程式

MinecraftInstaller.msi · 約 2.2 MB · 適用 Windows

  1. 按下「下載」按鈕
  2. 到電腦的「下載」資料夾找到 MinecraftInstaller.msi
  3. 點兩下打開它，照著畫面按「下一步」就完成囉！

第二步：下載 CurseForge

CurseForge 可以幫我們輕鬆安裝模組 (Mod) 和地圖。

⬇️ 下載 CurseForge 安裝程式

CurseForge Windows - Installer.exe · 約 2.9 MB · 適用 Windows

  1. 按下「下載」按鈕
  2. 到電腦的「下載」資料夾找到 CurseForge Windows - Installer.exe
  3. 點兩下打開它，照著畫面完成安裝
